# Tsumori 使用说明

## 1. 产品简介

Tsumori 用于记录和复习日语学习内容。系统会把每天新增的单词、短句、阅读和复习行为汇总到首页，帮助你连续积累并回看过去的学习成果。

账号统一登记在服务端数据库。学习数据可选择保存在当前浏览器，或同步到服务端云端。

## 2. 开始使用

### 2.1 注册与登录

首次打开系统时需要创建账号：

1. 选择界面语言。
2. 填写昵称、邮箱和密码。
3. 密码至少 8 位，并同时包含字母和数字。
4. 选择“本地存储模式”或“云端管理模式”。
5. 查看并同意隐私政策与使用条款。
6. 完成注册后进入首页。

账号会登记到服务端数据库。密码使用服务端 `scrypt` 加盐哈希保存，不保存明文。浏览器只保留登录令牌。

退出后可使用注册邮箱和密码重新登录。不同账号的学习数据相互隔离。

### 2.2 打开系统

在运行 Tsumori 的设备上访问系统地址。个人本地运行时，默认地址为：

```text
http://127.0.0.1:5173/
```

推荐使用较新版本的 Chrome、Edge 或 Safari。语音识别能力取决于浏览器和设备支持情况。

### 2.3 设置学习资料

进入“设置（Settings） > Profile”：

1. 选择解释语言。
2. 选择所属行业，用于匹配阅读主题和例句语境。
3. 选择当前日语等级（N5 至 N1）。
4. 设置 AI 结果是否自动加入单词本。
5. 设置 AI 返回的最大例句数量。
6. 点击“Save profile”保存。

### 2.4 切换界面语言

进入“设置 > 账号”，可选择：

- 中文
- English
- 日本語
- 한국어
- Tiếng Việt
- မြန်မာ

切换后导航、首页和各学习页面会立即使用所选语言，重新登录后仍会保留该偏好。

### 2.5 配置 AI

AI 理解助手和分级阅读生成功能需要用户自己的 API Key。

进入“设置（Settings） > API”：

1. 选择 Gemini、OpenAI 或 DeepSeek。
2. 填写对应服务商的 API Key。
3. 选择可用模型。
4. 点击“Save AI settings”。

注意：

- 当前版本会将 API Key 保存在本机浏览器中。
- 不要在公共电脑或他人设备上保存个人 API Key。
- AI 服务可能产生费用，具体以服务商计费规则为准。
- AI 生成内容可能存在错误，重要内容应自行核实。

## 3. 首页与每日记录

首页用于查看当天任务和学习成果。

### 3.1 每日打卡

点击首页右上方“完成今日打卡”。打卡后系统会保存当天状态和打卡时间。

打卡表示完成了当天计划，不会自动新增学习内容。建议在完成当天学习后再打卡。

### 3.2 昨日学习重点

首页会优先展示前一天新增的单词、短句或阅读内容，并提供“快速复习”入口。

点击“快速复习”后，会直接开始当前到期单词的复习。

### 3.3 每日学习报告

系统自动统计：

- 新增单词
- 收藏短句
- 完成复习
- 阅读文章

这些数据来自实际操作记录，不需要手动填写。

### 3.4 查看历史明细

在“最近 7 天”中点击任意日期，可展开当天记录，包括：

- 学习内容类型
- 单词、短句或文章名称
- 学习或复习时间
- 复习结果
- 当天是否打卡及打卡时间

旧版本中已经发生的打卡可能没有具体时间，但已有学习内容仍可显示。

## 4. 单词本

进入“Words / Vocabulary”。

### 4.1 新增单词

点击“Add word”，填写：

- 单词
- 读音
- 日文解释
- 中文解释或个人笔记

保存后，该单词会进入复习队列。

### 4.2 复习单词

点击“Review due words”，根据掌握情况选择：

- `Again`：没有记住，较快重新出现
- `Hard`：比较困难，缩短下次复习间隔
- `Easy`：已经掌握，延长下次复习间隔

系统使用间隔复习逻辑自动计算下次复习日期。

### 4.3 编辑与删除

在单词卡片中使用“Edit”修改内容，使用“Delete”删除。

删除后当前版本无法撤销，请谨慎操作。

## 5. 短句本

进入“Phrases”。

点击“Add phrase”可以保存：

- 日语原句
- 读音
- 翻译或笔记
- 使用分类

适合保存日常表达、商务表达、旅行用语和希望反复使用的完整句子。

当前版本短句本主要用于收藏和查看，尚未提供独立的间隔复习流程。

## 6. 日语理解助手

进入“Expert”。

输入日语、中文或英文内容后，系统可根据当前翻译方向生成：

- 翻译
- 日语读音
- 词性和含义
- 词语拆解
- 例句
- 语法与语感说明

结果页面支持：

- 朗读输入或输出
- 复制翻译
- 将重点词加入单词本
- 将表达加入短句本
- 查看和删除历史查询

使用前必须完成 AI 配置。

## 7. 分级阅读

进入“News”。

系统会根据学习等级和行业偏好查找候选主题。选择最多 3 个主题后，可使用 AI 生成适合当前等级的阅读文章。

阅读页面支持：

- 假名显示开关
- 全文或指定段落朗读
- 语速调整
- 重点词汇查看
- 查看原始主题来源

生成文章会消耗 AI API 配额。

## 8. 口语练习

进入“Speak / Speaking”。

1. 输入要练习的日语。
2. 调整播放速度。
3. 点击“Play audio”听参考朗读。
4. 点击“Start recording”进行跟读。
5. 浏览器支持语音识别时，系统会显示识别文本和相似度。

相似度只是文本匹配结果，不等同于专业发音评分。

## 9. 用户与数据

### 9.1 账号与存储模式

所有账号均登记在服务端。进入“设置 > 账号”可以切换：

- 本地存储模式：学习数据只在当前浏览器。更换设备时需导出和导入备份。
- 云端管理模式：学习数据同步到服务端，在其他设备登录后自动恢复。

从本地模式切换到云端模式时，当前学习数据会上传到云端。从云端切换到本地模式后，当前设备保留本地副本，之后的新变化不再上传。

### 9.2 数据备份

进入“Settings > Data”：

- `Export data`：将全部本地数据下载为 JSON 文件
- `Import data`：从此前导出的 JSON 文件恢复数据
- `Clear all local data`：清除当前浏览器中的全部 Tsumori 数据

建议定期导出，特别是在清理浏览器、重装系统或更换设备之前。

导入操作会写入当前浏览器的数据。执行前建议先导出一次现有数据。

## 10. 常见问题

### AI 功能无法使用

检查 API Key、模型选择、账号余额或配额，并确认本地服务正在运行。

### 手机和电脑数据不同

确认账号当前使用“云端管理模式”。本地存储模式不会自动同步，需要在原设备导出数据，再在新设备导入。

### 清理浏览器后数据消失

本地存储模式的数据保存在浏览器中，没有备份时无法恢复。云端管理模式重新登录后会从服务端恢复。

### 无法录音或识别

确认浏览器支持语音识别，并允许网页使用麦克风。部分浏览器或网络环境可能不支持该功能。

### 阅读或 AI 解释有错误

AI 内容仅作学习辅助。可重新生成、换用其他模型，或参考词典和权威资料核实。
