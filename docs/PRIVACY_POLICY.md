# Tsumori 隐私政策与使用条款

版本：2026-06-14

## 数据保存

账号信息、密码哈希、隐私政策同意记录和存储模式统一保存在服务端数据库。

用户可选择两种学习数据存储模式：

- 本地存储模式：学习记录保存在当前浏览器。清除浏览器数据、重装浏览器或更换设备可能导致未备份数据永久丢失。
- 云端管理模式：学习记录保存在服务端，并在用户登录其他设备时同步。

密码使用服务端 `scrypt`、随机盐生成哈希，系统不保存明文密码。浏览器仅保存登录会话令牌。

## AI 与第三方服务

使用翻译、学习解析或文章生成功能时，输入内容会发送给用户选择的 Gemini、OpenAI 或 DeepSeek 服务。

请勿输入密码、证件号码、支付信息、医疗信息、商业机密或其他敏感内容。第三方服务的数据处理规则以其自身政策为准。

## API Key

当前版本由用户自行提供 API Key。Key 保存在当前浏览器，并发送给本地 Node 服务以转发 AI 请求。

请勿在公共电脑、共享账号或不受信任设备上保存 API Key。

## AI 内容

AI 输出仅用于语言学习辅助，可能包含错误、遗漏或不自然表达。涉及工作、法律、医疗、财务或其他重要用途时，应通过权威资料或专业人士核实。

## 用户控制

用户可以：

- 在设置中导出当前账号的学习数据
- 导入此前导出的学习数据
- 在本地存储和云端管理模式之间切换
- 清除本地数据
- 退出当前账号

本地模式下未备份的数据无法由系统恢复。切换到云端模式时，当前浏览器的学习数据会上传到用户的云端空间。

## 同意记录

注册时必须主动勾选同意本政策。系统会在服务端账号记录中保存政策版本和同意时间。
